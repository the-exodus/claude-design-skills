# Tessera lexicon

Started in March 2023; consolidated 2026-09-19.

Gaps (proposed, not yet admitted): *stack* — the tiles of the main-stack layout other than the main tile.

A term earns an entry when it is language rather than code, needs defining, and is the one word for its concept.

---

**floating window** — A window that belongs to a *workspace* but has no *tile*. Distinct from an *unmanaged window*, which belongs to no workspace.

**layout** — The scheme by which a *workspace*'s tiled windows get their *tiles*: main-stack or columns.

**main tile** — The *tile* on the left of the *work area* in the main-stack *layout*.

**move** — To relocate the focused window to another *workspace* and take the user there with it. Distinct from *send*, which leaves the user where they are.

**promote** — To exchange the focused window with the window in the *main tile*. "zoom" is not used. (Rename awaiting sign-off.)

**rule** — A user-written instruction that matches windows and says how to treat them.

**send** — To relocate the focused window to another *workspace* while the user stays. Not to be confused with *move*.

**split ratio** — The share of the *work area*'s width given to the *main tile*.

**tile** — The rectangle of a monitor's *work area* that a *layout* assigns to one window. "pane" is not used.

**unmanaged window** — A window Tessera ignores: it belongs to no *workspace* and no command touches it. Distinct from a *floating window*.

**work area** — The part of a monitor that windows may occupy.

**workspace** — A numbered set of windows belonging to one monitor.
