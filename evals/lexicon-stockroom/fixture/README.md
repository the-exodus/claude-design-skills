# Stockroom

Stock, reservations and picking for a single warehouse. Stockroom tracks
on-hand per bin, reserves stock for incoming orders, allocates bins when a
wave is released, and prints packing slips at the pack bench.

- `stockroom/` — the service
- `docs/operators-guide.md` — for warehouse operators
- `docs/api.md` — the HTTP API
- `docs/decisions/` — decision records
- `GLOSSARY.md` — the terms we use
